# 結帳串接 Google 試算表

網站結帳 → Google Apps Script（GAS）→ 寫入 Google 試算表。

```
顧客按「送出訂單」
   └─ index.html 用 fetch POST 訂單（品項代碼、數量、取餐方式、聯絡資料）
        └─ GAS doPost：驗證欄位、用自己的價目表重算金額、上鎖避免同時寫入
             ├─ 「訂單」工作表：一筆訂單一列（含狀態下拉選單）
             ├─ 「訂單明細」工作表：一個品項一列
             └─ 回傳訂單編號 → 網頁顯示「訂單編號 GE251116-0001」
```

## 設定步驟（約 5 分鐘）

1. 到 Google 雲端硬碟建立一份新的 **Google 試算表**（名稱自訂，例如「金邊鍋貼訂單」）。
2. 在試算表選 **擴充功能 → Apps Script**，把預設內容全部刪掉，貼上本資料夾 `Code.gs` 的全部內容，儲存。
3. 上方函式選單選 **setup**，按 **執行**。第一次會要求授權，選自己的帳號並允許。
   完成後試算表會多出「訂單」「訂單明細」兩張工作表。
4. 右上 **部署 → 新增部署作業**，類型選 **網路應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   按 **部署**，複製 **網路應用程式網址**（結尾是 `/exec`）。
5. 把網址貼到 `index.html` 裡的這一行，然後提交、推送：

   ```js
   const GAS_URL = 'https://script.google.com/macros/s/……/exec';
   ```

`GAS_URL` 留空時，網站維持原本的示範模式（不送出任何資料）。

## 之後修改

- **改了 `Code.gs`**：要到 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**，網址不變才會生效。
- **改菜單或價格**：`index.html` 的 `catalog` 和 `Code.gs` 的 `CATALOG` 要一起改。金額以 `Code.gs` 為準。
- **想收 Email 通知**：把 `Code.gs` 最上面的 `NOTIFY_EMAIL` 填上信箱，重新部署新版本。

## 注意

- 網路應用程式網址是公開的，任何人都能對它送資料；`Code.gs` 會驗證欄位與重算金額，但擋不了有人刻意灌假訂單。接單量大或要收款時，應改用正式的後端與金流。
- 試算表裡會有顧客姓名、電話、地址，請只分享給需要處理訂單的人。
